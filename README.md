# [SUBARU インプレッサ STI GRB] ESP32 DIY クルーズコントロール(ASCD) & オートライト

ESP32マイコンを使用した実車用クルーズコントロール（ASCD）および自動ヘッドライト制御（オートライト）の統合システムです。  
実車の車速パルスとアクセルペダル位置信号（APPS）を取得・制御し、PID演算によって目標車速をリアルタイムに維持します。

## 1. システム概要

本システムは1台のESP32で以下の機能を独立して制御・モニタリングします。

1. **オートスピードコントロール（ASCD / クルーズコントロール）**
   - 車速をCANで受信し、純正ペダル電圧を計測しPID制御によるスロットル（APPS）電圧調整
   - TOYOTAのASCDスイッチを利用したI/F
   - ブレーキ割り込みおよび異常検知時の即時フェールセーフカットオフ
2. **オートライト制御**
   - エアコン用照度センサーを用いた周囲照度測定によるヘッドライト自動点灯・消灯(詳細の説明は割愛します)
3. **ステータス表示**
   - 0.96インチ OLED ディスプレイによる車速・設定状態のリアルタイム表示

## 5. 回路設計と安全対策（フェールセーフ）

自動車環境特有のサージノイズと物理的安全性に対処するため、多重の保護回路を実装しています。

1. **ハードウェア優先カット（最重要）:**
   ブレーキペダル踏み込み時は、ESP32の処理状態に関わらず物理リレーにより純正アクセル信号（APPS）へ強制復帰します。
2. **制御準備監視**
   処理がLoop()に入ってからKILL_SWITCH_PINをHIGHにし、この出力によりリレーがONになる。そこからPWM出力が車両側へ伝わる。

3. **電圧レベル変換 & 分圧保護:**
   実車のアクセル信号（0.6V〜3.5V）に対し、ESP32のADC上限（3.3V）を超えないよう抵抗分圧回路を配置。

## 5. 制御概要

本クルーズコントロールシステムは、通常のPID制御に加えて実車（特にMT車および物理ブレーキ非連動環境）での追従性・快適性・安全性を確保するための様々な独自の制御工夫を盛り込んでいます。

### 5.1 PID制御とブレーキ非使用（アクセル制御のみ）による工夫点
物理ブレーキを作動させずアクセルペダル開度（PWM出力）のみで制御するため、滑らかな加減速とオーバーシュートの抑制、および下り坂・登坂路での追従性が重要となります。

👉 [ロジックフローチャート](Docs\LogicFlowChart.md)

- **ソフト不感帯（Soft Deadband）＆ 降下時非対称不感帯:**
  - 目標車速 $\pm 0.3\,\text{km/h}$ の範囲内では積分項（I項）の更新をストップ（ホールド）し、アクチュエータの過剰なハンチングを防ぎます。
  - **降下時非対称不感帯:** 車速が低下中、または目標を超過した状態から降下してくる際は、マイナス側の不感帯を $-0.05\,\text{km/h}$ と浅く自動切り替えし、目標車速を割り込む直前から早期にアクセル出力を立ち上げてボトム落ちを防ぎます。
- **動的I項クランプ（Floor保証付き `I_DECAY`）:**
  - 下り坂等で実車速が目標車速を $+1.0\,\text{km/h} \sim +4.0\,\text{km/h}$ 超過した際、超過量に応じてI項の上限（通常15%）を動的に引き下げ、超過後の過剰なアクセル残存を抑圧します。
  - 削りすぎによる目標割れ時の沈み込みを防ぐため、下限値（Floor: `3.0%`）を保証しています。
- **3秒車速トレンドによる予測フィードフォワード（`FF_TREND`）:**
  - 登坂路などで車速が落ち込む際、瞬間的なD項（微分）ノイズに左右されず、過去3秒間の車速低下量が `1.5 km/h` 以上かつ目標から `2.0 km/h` 以上離れた場合に予測的にアクセル開度を加算（最大 `5.0%`）し、追従遅れを解消します。
- **内部目標車速のランプ制御（`RAMP_UP`）:**
  - 設定車速変更時や復帰（Resume）時、急激な踏み込みショックを防ぐため、内部目標車速を `5.0 km/h/s` のレートリミットで滑らかに追従させます。
  - ドライバーのアクセル踏み込み（オーバーライド）時は内部目標速度を自車速に即時追従させ、離した後は1秒間のホールド時間を経てシームレスに制御を引き継ぎます。
- **折れ線Pゲイン（`P_HIGH`）:**
  - 車速差が $\pm 1.0\,\text{km/h}$ 以内は通常Pゲイン（`1.5`）、超過時は高Pゲイン（`3.0`）を適用し、大誤差時からの素早い復帰を実現しています。

### 5.2 MTへの対応 (クラッチを踏んでギアを変える時の制御)
- **変速中の制御一時抑制と上位ギア自動追従:**
  - クラッチペダル切断（`clutchReleased == false`）時、切断直前のギアを記憶します。
  - シフトチェンジ中、エンジン回転数低下等により記憶したギアより上位のギア段が検出された場合のみ、半クラッチでギアが接続し始めたと判断して自動的にPID制御を再開します。
  - 同一ギアのままやニュートラルの場合は、エンジンの空吹かしを防ぐため出力を即座に `0%` に制限します。


### 5.3 MTへの対応 (ニュートラルに入れた時の制御)
- **ニュートラル（Gear: 0）自動キャンセル:**
  - クラッチ切断からニュートラル位置でクラッチが離された場合、空吹かしや意図しない加速を防ぐため、ブレーキを踏んだ際と同様に**クルーズ制御を自動キャンセル**します（目標車速は保持されるため、後にResume操作可能）。


### 5.4 MTへの対応 (エンジンブレーキによるギクシャクを抑える)
- **オーバーライド操作時の積分項バックキャルキュレーション（`syncIntegral`）:**
  - ドライバーがアクセルを踏み込んでクルーズ制御を一時的に追い越した（オーバーライド）際、PIDの計算値より実アクセル開度（`realPedalADC`）が大きければ、実アクセル開度に相当するI項をバックキャルキュレーション（逆算・同期）します。
  - これにより、追い越し後にアクセルを急に離した際、PID出力と実アクセル開度がスムーズに接続され、急激なエンジンブレーキによるギクシャク感（ショック）の発生を完全に防ぎます。
- **セレクトハイ（Select-High）出力制御:**
  - PID計算出力と実アクセルペダル開度のうち、常に大きい方の開度をPWMとして採用し、ドライバーの意図した加速操作を妨げません。
## 6. 状態遷移

本クルーズコントロールシステムは、安全性の確保とMT車特有の操作性（シフトチェンジ・空吹かし防止）に対応するため、以下の4つの主要状態（ステート）を遷移します。

- **`STANDBY` (初期状態):** 目標車速が未設定の状態。
- **`OFF_READY` (制御待機):** ブレーキ踏み込み、CANCEL操作、ニュートラル判定等により制御が待機状態。設定車速は保持されResume可能。
- **`ACTIVE_DRIVING` (制御中):** 設定目標車速に向けてPID演算およびアクセルPWM出力を行っている状態。
- **`ACTIVE_CLUTCH` (MTシフト中):** クラッチ切断中の一時状態。エンジンの空吹かしを防ぐため出力を0%制限（ただしシフトアップ判定時は先行PID出力）。

## 9. 開発中の注意点


### 8.1 アクセルペダル接続をしないで、車両電源をIGNにした場合
ECUは電圧を常に監視しているため、未接続のままIGN ONにしたり、正しい制御出力ができていない場合には車両がフェールに落ちます。ELM327などを用意してDTCを消せるようにしておくと良いでしょう。
