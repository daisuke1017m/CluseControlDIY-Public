# OLEDピン配置
| 機能 | 色  | 接続先 |
| ---- | --- | ------ |
| VCC  | 赤  | 3.3V   |
| GND  | 黒  | GND    |
| SCL  | 白  | GPIO22 |
| SDA  | 黄  | GPIO21 |

# OLED 仕様
特徴:
OLED自己発光、バックライトなし。
サイズ：0.96インチ。
ドライバーIC：SSD1306。
電圧: 3.3V-5V DC。
視野角：> 160°。
高解像度：128 x 64。
動作温度：-30°C～70°C。
ディスプレイ：黄色2列、青6列
モジュールサイズ: 27mmx 27mm x 4mm。
スクリーン素材：ガラス。優れた保護が必要です。
I2C インターフェイス：
GND: グラウンド。
VCC: 3.3V~5V。
SCL：I2C シリアルクロック（UNO：A5；MEGA：21）
SDA: I2C シリアルデータ (UNO: A4; MEGA: 20)。
