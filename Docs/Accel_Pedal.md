## アクセルペダルのピン配置
ペダルのコネクタロックがある方を上にして左から1,2,3,4,5,6ピンと定義する
### 調査
1. ペダルを外す
2. ペダルのハーネスを外す
3. 車両側のピンを調べる
4. ペダル側のピンを調べる
---
【車両側のピンを調べる】
車両アースからの抵抗値を調べた

| 車両側のピン番号 | アースからの抵抗値 | 備考                     |
| :--------------- | :----------------- | :----------------------- |
| 1                | 180Ω               | 電源または信号           |
| 2                | 0kΩ                | アース線であることが確定 |
| 3                | 30kΩ               | 電源または信号           |
| 4                | 180Ω               | 電源または信号           |
| 5                | 0Ω                 | アース線であることが確定 |
| 6                | 30kΩ               | 電源または信号           |

**アースとMainとSubの2系統がある**

---
【ペダル側のピンを調べる】
5Vをかけて電圧を調べる。5VはUSB電源を使用
1,4に5Vをかけて2,5と3,6間の電圧を確認した。
ペダルの動きに合わせて0.6V～4.5Vの範囲で動作

### ピン配置が確定
| ピン番号 | 役割             | 系統            | 接続した線             |
| -------- | ---------------- | --------------- | ---------------------- |
| 1        | VC1 （5V電源）   | A系統（メイン） |                        |
| 2        | E1 （アース）    | A系統（メイン） | （黒）                 |
| 3        | VTA1（信号出力） | A系統（メイン） | ペダル→黄→ESP32→赤→ECU |
| 4        | VC2 （5V電源）   | B系統（サブ）   |                        |
| 5        | E2 （アース）    | B系統（サブ）   | （白）                 |
| 6        | VTA2（信号出力） | B系統（サブ）   | ペダル→緑→ESP32→青→ECU |

##　実際の電圧範囲の調査
ペダルを車両に戻しハーネスを接続し、センサーのGNDと信号線の電圧を測定した。0.6V～3.5Vの範囲で動作している。
おそらく5Vの電源で吊っている。

###　電圧測定の方針
ESP32は3.3Vまでなので、分圧して入力する
