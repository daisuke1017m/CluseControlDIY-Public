### 車速差・エラー領域別 制御パラメータ比較表

| 領域                        | 車速差 `raw_error` [km/h]<br>(`目標車速 - 実車速`) | 有効エラー `error` [km/h] | Pゲイン `Kp`              | Iゲイン `Ki`             | I項上限 `dynamic_max_i`             | PWM出力・挙動の概要                                                                  |
| :-------------------------- | :------------------------------------------------- | :------------------------ | :------------------------ | :----------------------- | :---------------------------------- | :----------------------------------------------------------------------------------- |
| **① 大幅超過**              | `raw_error <= -4.0`                                | `raw_error + 0.3`         | **3.0** (`Kp_High`)       | **0.30** (`Ki_Decay`)    | **0.0%** <br>(正のI項完全消去)      | 下限 **3.0%** 固定（エンブレ無効化）。過剰な踏み込みを徹底排除。                     |
| **② 中度超過**              | `-4.0 < raw_error <= -1.0`                         | `raw_error + 0.3`         | **1.2** (`Kp`)            | **0.30** (`Ki_Decay`)    | **15.0% → 0.0%** <br>(線形引き下げ) | 車速超過量に応じて正のI項上限を滑らかに縮小。ショックなく減速。                      |
| **③ 微小超過**              | `-1.0 < raw_error < -0.3`                          | `raw_error + 0.3`         | **1.2** (`Kp`)            | **0.30** (`Ki_Decay`)    | **15.0%**                           | 高速減衰ゲイン `Ki_Decay` により、蓄積されたI項を素早く減衰。                        |
| **④ 不感帯 (デッドバンド)** | **`-0.3 <= raw_error <= +0.3`**                    | **`0.0`**                 | **1.2** (`Kp`)            | **-** <br>(更新ホールド) | **15.0%**                           | **P項 = 0%**、**I項更新停止**。<br>`ベースライン(8%) + 学習済みI項` でアクセル固定。 |
| **⑤ 通常加速**              | `+0.3 < raw_error <= +5.0`                         | `raw_error - 0.3`         | **1.2** (`Kp`)            | **0.13** (`Ki`)          | **15.0%**                           | デッドバンド分を引き算した有効エラーで目標へ滑らかにアプローチ。                     |
| **⑥ 遠距離加速**            | `raw_error > +5.0`                                 | `raw_error - 0.3`         | **3.0** (`Kp_High`折れ線) | **0.13** (`Ki`)          | **15.0%**                           | 近距離(1.2)と遠距離(3.0)を連続的につなぐ折れ線ゲインで力強く加速。                   |
